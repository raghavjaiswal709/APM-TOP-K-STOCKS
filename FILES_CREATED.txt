TROUBLESHOOTING QUICK FIXES
═══════════════════════════════════════════════════════════════════════════════

Issue: Port already in use
  → lsof -i :3000 (find what's using it)
  → kill -9 <PID> (kill it)
  → Or change in .env file

Issue: Instance won't start
  → cd multi-instances && ./manager.sh logs 1 (check logs)
  → docker-compose down && docker-compose up -d (restart)

Issue: Database error
  → Check DATABASE_URL in .env
  → Verify db container is running: docker ps | grep db

Issue: Out of memory
  → docker system prune -a (free space)
  → Check usage: docker stats
